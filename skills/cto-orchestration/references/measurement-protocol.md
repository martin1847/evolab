# 测量协议骨架（测量 / 评测类 goal 附录）<!-- trunk:测量协议 -->

> 触发：goal 的 Done-when 含测量 / 评测 / 对比判定（A/B 因果、命中率、性能基准、评测报告）——
> goal-template 场景条款「测量/评测类」行命中即读本文，逐条款对照实例化进 goal；goal-review
> 命中测量面时按同一清单复核，任一条款缺失即 blocking。
> 分工：仪器六问（review-dispatch）审「量具本身可信吗」——量具自证判别力、坏样本变异、负对照
> 归那边；开测前提的事实核验归 goal-template Premises 节；本文只管「测量过程可信吗」，三处互不复制。

**证据阶梯**（headline 结论的每格证据按层级锚定）：真实结局 > 环境状态 > 执行轨迹 > 模型评判 >
被测自报。headline 须锚定前两级；轨迹只作佐证；模型评判须过条款 3 且可独立复判；被测自报永不作证据。

## 七条款（每条 = 判据 + 缺失时的失败模式）

1. **身份冻结**：量具代码 / 题面集 / 评判规则 / 期望值各产物开测前内容哈希入 manifest；任何变更 =
   新批次，禁与旧批合并或跨批择优。（缺 → 判定输入可被事后选择性满足，改题面把红改绿不可见。）
2. **配对与顺序**：对比类测量逐样本邻近配对、顺序预注册且确定，禁重排、禁挑样本；无法配对抵消
   漂移时如实降级为单臂描述，不出对比结论。（缺 → 时间漂移 / 顺序效应混进臂差。）
3. **评判独立与盲化**：评判者（人 / 工具 / 模型）的输入不含臂身份与预期结论；评判者与被测对象
   同源（自判）只作诊断证据，不得单独支撑 headline。（缺 → 判定向预期滑动，利益冲突不可见。）
4. **三态真值表 + 恒定分母**：每样本必落三态之一（如 PASS / FAIL / INCONCLUSIVE，桶名可按场景
   重命名，三态互斥完备不可减）；错误分型闭集枚举、仪器噪声与产品损害分列；headline 只报计数 /
   区间，分母恒为预注册样本量——ERROR 与剔除样本计入 INCONCLUSIVE，不缩分母。禁单点结论。
   （缺 → 缺证被包装成更高点估计，先验答对计入成功分子。）
5. **人群与版本预注册**：分析人群开测前冻结；重试默认诊断性、不进主分析集；被测版本与每次观测
   一一绑定，混合版本窗口 = INCONCLUSIVE。（缺 → 选择性重试 / 跨版本混窗制造有利结果。）
6. **停止与重跑纪律**：时间 / 次数预算预注册，耗尽或中止 = INCOMPLETE、禁出 headline。噪声剔除
   类别开测前预定（事后新增类别无效）；报告保留 total / included / excluded 计数与逐行原因；
   已落定批禁整批重跑，整批环境性失效（全部行命中预设剔除类别、或 included 低于口径下限）才
   允许重测一批，两批数据都留、禁择优。（缺 → 重测边界被事后发明，坏批悄悄消失。）
7. **结论输出形状**：结论区用固定结构化字段，含不可判样本计数；样本量不足以支撑方向性结论时
   字段强制标注；结论文本过禁用方向性词表自查——「提升 / 回归 / 恶化」类措辞须有支撑格，无格
   即删词。（缺 → 禁语只是声明句，方向性措辞从叙事缝里溢出。）
