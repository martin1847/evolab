# 异构冷评审（heterogeneous cold review）

> 让写代码的模型自查，它会沿同一条推理链再走一遍，然后告诉你没问题。
> 评审的价值不在「再看一遍」，在**去相关**：换血统、断上下文、出口双面闸。
> 一句话：**评审者与实现者的错误必须不相关，评审才有信息量。**

## 为什么同会话自评近似安慰剂

- 同模型 + 同上下文自查 = 相关错误：同一训练偏置、同一推理链、同一处锚定，实现时看不见的洞
  复查时同样看不见。冷上下文反锚定有定量背书（arXiv 2603.12123：冷上下文评审 F1 显著高于
  同会话自评，收益来自 context separation 本身）。
- 本仓实证：一次未过评审的 guard 改动把 S1 级永久 bypass 带进了攒批，作者会话全绿，异构冷评审
  首轮抓出；另一次规范镜像把同一节双贴三处、直接进了公开版，也是评审抓出后才补的机器门。

## 三条去相关轴

1. **换血统（heterogeneity）**：执行席与评审席用不同 lineage 的模型。工具名不证明异构——看实际
   model/backend 与 quota 池，别让两席落进同一家。
2. **断上下文（cold context）**：评审 brief 只给「查哪些轴 + verify don't trust + 达标线」，
   不夹带实现者的结论与倾向。喂结论 = anchoring：换了模型却共享推理链，血统白换。
3. **出口双面闸**：源头激进找（克制型措辞是漏报机器），出口按证据档过滤——**晋级须复现**
   （blocker/major 须探针/失败测试执行复现）、**删除须证伪**（「仅仅无法验证」不构成删除理由，
   防 verifier 变成第二个噪声源）。

## 共模盲区：自证三件套齐了仍测不出的那类错

去相关不只评审要，**自证本身更要**。三联控制（坏样本红/好样本绿/坏了报 ERROR）管的是样本
**存在**，不管样本**从哪来**：当量具、坏样本、"要防哪类损坏"的命名出自同一颗脑袋，模型错误
对三者是**共模**的——三件套全过，测出的只是模型自洽。这与冗余系统的 common-cause failure
同构：N 份相同实现挡不住共因故障，N 份自证挡不住共模模型错；有效的是**多样性**，不是数量。

- 实证 ①：「表是路由唯一真源」的契约测试，作者出的四枚变异全打在表与注册表上，三件套全绿；
  异构评审换个采样（改真实握手动词/投影/启动分支名），72 断言纹丝不动——承诺已假，量具照绿。
- 实证 ②（同日同病，随手尺度）：grep 统计阻塞频次，62/63 命中全是模板底注的说明文本——
  探针作者与探针对象共享同一份"BLOCKED 长什么样"的模型。
- 破法只有异源两路，成本从低到高：**异构出题**（评审那轮顺手产出打在承诺面的变异清单，
  实现者逐条做红——把去相关从"评审时"提前到"立仪器时"，边际成本零）；**消费者反推**（这句
  承诺骗到读者时，世界上什么会变坏——从损害端往回找观察面）。判据一句话：坏样本必须打在
  **承诺面**（读者会信的那句话），打在实现中间结构（内部表/自洽性）的不算自证。

## 与自动评审产品的分界（外部对照）

大规模自动评审产品（如 2026 开源的 alibaba/open-code-review，内部服务过数万开发者）走的是另一半：
**确定性工程包住单模型 agent**——文件筛选决策树、路径 glob → 规则清单确定性注入 prompt、滑动窗口
行级定位、外挂「只许证伪」filter pass。两个观察：

- 它的 filter pass 是**同一个模型再问一遍**——正是异构评审要规避的相关性陷阱；它的「规则按路径
  确定性注入」则被我们反向收编为 path→轴映射表（见 cto-orchestration `references/review-dispatch.md`）。
  两套系统站在同一条分界线两侧：**能确定判定的进结构；需要判断的给 agent；对判断的判断（评审）
  给另一个不相关的 agent。**
- 值得注意的负例：它的 CI 门禁只看进程退出码、**不按 finding severity fail**——把 LLM finding
  直接当硬门，连大规模生产部署都没敢。硬门要绑的是**人裁决过的 verdict**（评审 attest 类机制、
  绑定 tip 用后即焚），不是模型原始输出。

## 收敛与止损（缺了这节循环会永动）

- ledger 分栏（blocking / queued / advisory / pre-existing），只有 blocking 驱动续轮；第 3 轮起
  续派须书面举证 SHIP-BLOCKING；同一 finding 修复连续 2 轮无净进展即止损转人工。
- 裁决沉淀为 skip rules 回写项目治理文档（别再报），漏轴 post-mortem 落映射表新行（别再漏）——
  单次记忆升为跨评审结构。

## 诚实边界

- 异构 ≠ 无关：不同 lineage 仍共享数据分布与人类代码语料，去相关是程度不是开关。
- 冷上下文有成本：评审者要自己重建理解，深仓贵——按风险分档，低风险走轻量 review，不全量对抗。
- 复现闸对纯设计类 finding 无探针可执行——那类走人工裁决，别硬造探针冒充证据。
